description: "World Monitor 的 nuclear 变体：面向美国所有核设施的全灾种信息中心，基于 NRC、DOE、EIA、EPA、USGS、NWS 与 NASA 的开放数据构建。"

NucMonitor 是 `nuclear` 站点变体。它把 World Monitor 仪表盘变成一个统一入口，用来回答"今天某个美国核设施及其周边正在发生什么"：哪些反应堆在运行、NRC 记录了什么、附近有哪些灾害、辐射监测站看到了什么，以及监管机构和业界在说什么。

本地运行 `npm run dev`（本分支默认即为 nuclear 变体）或 `npm run dev:nuclear`；构建使用 `npm run build:nuclear`。在线部署时，`nuclear.<域名>` 以及任何包含 `nucmonitor` 的主机名都会解析为该变体。

## 设施注册表

`src/config/us-nuclear-facilities.ts` 是一个无任何导入的纯数据模块，浏览器、node 测试、种子脚本和 MCP 层都可以直接读取。每条记录包含 `id`、`name`、`category`、`status`、州、坐标、运营方、监管方，以及可选的 NRC 案卷号、机组列表、ISFSI 标记、参考链接、备注和 `statusAliases`（用于匹配 NRC 状态报告中的机组名称）。

类别：

- `power-reactor`：55 处拥有在运机组的厂址，含 Vogtle 3、4 号机组与 Palisades 重启。
- `restart`：Crane 清洁能源中心（TMI-1）与 Duane Arnold。
- `new-build`：Natrium（Kemmerer）、Kairos Hermes、X-energy Long Mott、ACU MSRR、TVA Clinch River BWRX-300、Holtec SMR-300、Oklo Aurora、Fermi America，以及已放弃的 V.C. Summer 2、3 号机组。
- `decommissioning`：永久停堆厂址、仅剩 ISFSI 的厂址，以及已封存的示范堆。
- `doe-site`：国家实验室、NNSA 生产基地、海军堆实验室，以及环境管理与遗留管理场址。
- `fuel-cycle`：浓缩、转化、燃料制造，以及处于许可审查中的 TRISO 与激光浓缩项目。
- `research-reactor`：NRC 许可的大学、政府与工业研究堆。
- `uranium-recovery`：在运的常规铀矿加工厂与原地浸出项目。
- `waste`：WIPP、Yucca Mountain、两处已获许可的集中中间贮存设施、商业低放废物处置场，以及 GE Morris。

`US_NUCLEAR_REGISTRY_AS_OF` 记录审核日期。装机容量为夏季净电功率；许可证年份为当前 NRC 运行许可证到期年份（已获延期或二次延期者按延期后计）。引用任何数值前请先核对链接的 NRC 或 DOE 页面。`summarizeUsNuclearFleet()` 生成机组统计，`matchNrcUnitName()` 把 `Saint Lucie 2` 这类 NRC 状态标签解析为设施与机组。

编制注册表所用的来源：

- [NRC 在运反应堆列表](https://www.nrc.gov/reactors/operating/list-power-reactor-units.html) 与 [设施定位器](https://www.nrc.gov/info-finder/region-state/)
- [NRC 动力堆退役](https://www.nrc.gov/info-finder/decommissioning/power-reactor/)、[研究与试验堆](https://www.nrc.gov/reactors/non-power/)、[燃料循环设施](https://www.nrc.gov/materials/fuel-cycle-fac.html)、[铀回收](https://www.nrc.gov/materials/uranium-recovery.html)、[新建反应堆](https://www.nrc.gov/reactors/new-reactors.html)
- [DOE 环境管理场址](https://www.energy.gov/em/mission-and-sites) 与 [NNSA 站点](https://www.energy.gov/nnsa/nnsa-locations)
- [EIA 核能](https://www.eia.gov/nuclear/) 与 [IAEA PRIS](https://pris.iaea.org/PRIS/CountryStatistics/CountryDetails.aspx?current=US)

## NRC 反应堆状态数据源

NRC 发布一个竖线分隔的批量文件 `PowerReactorStatusForLast365Days.txt`，每台机组每个日历日一行（`ReportDt|Unit|Power|Reason|Change|...`）。nrc.gov 不返回 CORS 头，因此 `api/nrc-reactor-status.js` 以 `text/plain` 原样转发该文件，并做表头校验、8 MB 上限和 30 分钟共享缓存。它在 `api/api-route-exceptions.json` 中登记为 `upstream-proxy`。

`src/shared/nrc-reactor-status.ts` 按表头名称解析各行（上游列顺序可能变化），构建含前一日对照的最新日快照，并汇总机组功率。`src/services/nrc-reactor-status.ts` 经代理抓取（带断路器）并用注册表记录丰富每台机组。面板在视口附近时每 30 分钟刷新一次（`REFRESH_INTERVALS.nrcReactorStatus`）。

对 nrc.gov 的实时抓取仍需在能访问 nrc.gov 的部署环境中验证；解析器由 `tests/nrc-reactor-status.test.mts` 中的夹具覆盖。

## 全灾种关联

`src/services/nuclear-facility-hazards.ts` 是纯函数模块：`correlateFacilityHazards(inputs, options)` 接收仪表盘已加载的各类数据源，为每处设施返回一份报告，列出其监视半径内的全部信号、严重度与排序分值。默认值：

| 数据源 | 半径 | 时间窗 | 严重度规则 |
|---|---|---|---|
| USGS 地震 | 100 km | 72 小时 | M6+，或 50 km 内 M5+ 为 critical；M5+，或 50 km 内 M4+ 为 high |
| NWS 预警 | 多边形包含，无多边形时距中心点 60 km | 至 `expires` | Extreme 或飓风 / 龙卷风 / 山洪紧急警报为 critical；Severe 或任何 warning 为 high |
| NASA FIRMS 火点 | 25 km | 当前探测 | 每处设施合并为一条信号；距离、峰值 FRP 与数量决定严重度 |
| RadNet / Safecast | 80 km | 当前异常 | 经多源印证的尖峰为 critical |
| NHC / EONET 风暴 | 250 km，取到预报路径最近点的距离 | 未关闭事件 | 150 km 内三级以上为 critical |

被列出仅表示应当查看链接的来源与 NRC 事件通报，并不表示该厂址受到影响。每当 `data-loader` 推送新的地震、气象、火点、辐射或自然事件批次时，面板都会重新关联。

## 地图图层

`usNuclearFacilities` 是新增的 `MapLayers` 键，支持 DeckGL 与 SVG 渲染器，带有精选的图层说明卡、命令面板开关，以及一个 `usNuclear` 弹窗，展示类别、运营方、监管方与 NRC 区域、机组、备注、参考链接和案卷号链接。全球 `nuclear` 图层（World Monitor 的全球核设施）在该变体上仍可用，但默认关闭。

新增第七个变体涉及的常规位置：`SITE_VARIANTS` 与主机名检测、`VARIANT_META`、SEO 段落、`WEB_DASHBOARD_VARIANTS`、`NUCLEAR_PANELS` / `NUCLEAR_MAP_LAYERS` / `NUCLEAR_MOBILE_MAP_LAYERS`、`NUCLEAR_FEEDS`、`VARIANT_LAYER_ORDER.nuclear`、面板分类、命令、任务预设 `nuclear-hub`、页眉切换器与移动端菜单、嵌入与 WebMCP 监视器枚举、CORS 与 Sentry 主机白名单、`vercel.json` 重写与 CSP（frame-src / frame-ancestors）及 docker nginx 同步、内联引导脚本哈希、package 脚本（dev / build / test:e2e:nuclear）、文档页与导航、来源署名目录条目，以及重新生成的产品事实。

nuclear 子域名有意未加入 WebMCP origin-trial 主机集合和 `Origin-Agent-Cluster` 规则：这两处都需要为精确来源签发的 Chrome origin trial 令牌，本仓库无法生成。
